# ۱۴. وضعیت طرح پیشین جست‌وجوی هوشمند آفلاین

**لغوشده در ۲۰۲۶/۱۱/۱۰ به درخواست مالک پروژه.** موتور آزمایشی، واژه‌نامهٔ مخصوص، ابزارهای ارزیابی و فرمان build_search_lexicon حذف شدند. برنامهٔ قبلی ساخت بردارها، Elasticsearch، WebAssembly و بستهٔ مستقل مدل مبنای توسعهٔ فعلی نیست. نسخهٔ تاریخی متن طرح در تاریخچهٔ Git باقی است.

این حذف، جست‌وجوی مورد استفادهٔ اپ را تغییر نمی‌دهد: کاتالوگ tagging، مفهوم‌ها، نگاشت مقاله‌ها، عنوان، پیشنهادها، فیلتر تخصص، صفحه‌بندی و جست‌وجوی روی بستهٔ محتوای آفلاین حفظ شده‌اند. استخراج و بررسی مقصد پاراگراف نیز چون API مقاله به آن وابسته است باقی ماند.
