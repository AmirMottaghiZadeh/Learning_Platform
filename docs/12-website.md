# ۱۲. سایت `pharmenta.ir` و پنل محتوا

سایت معرفی، بلاگ، صفحهٔ پلن‌ها و خرید، صفحهٔ دانلود اپ و پنل مدیریت محتوا، همه در اپ `apps.website` همان بک‌اند Django اجرا می‌شوند. سرویس جدایی ندارد.

## مسیریابی بر اساس دامنه

`apps.website.middleware.SiteHostMiddleware` بر اساس `Host` درخواست تصمیم می‌گیرد:

- **هاست‌های `SITE_HOSTS`** (پیش‌فرض `pharmenta.ir` و `site.localhost`) سایت را می‌گیرند. urlconf آن‌ها `config/urls_site.py` است.
- **`www.` هر هاست سایت** به نشانی بدون www هدایت می‌شود.
- **هر هاست دیگر** (مثل `api.pharmenta.ir`) API را می‌گیرد.

هاست‌های سایت خودکار به `ALLOWED_HOSTS` و (با `https://`) به `CSRF_TRUSTED_ORIGINS` اضافه می‌شوند. محلی: `http://site.localhost:8000/`.

## صفحه‌های عمومی

| مسیر | صفحه |
|---|---|
| `/` | صفحهٔ اصلی (بلوک‌های قابل ویرایش در پنل) |
| `/blog/`، `/blog/category/<slug>/`، `/blog/tag/<slug>/`، `/blog/<slug>/` | بلاگ، دسته، برچسب، مطلب |
| `/blog/<slug>/comment/` | ارسال نظر (پس از تأیید در پنل نمایش داده می‌شود) |
| `/plans/` | پلن‌ها و قیمت‌ها (از `apps.billing`) |
| `/checkout/<price_id>/` | خرید، با کد تخفیف اختیاری |
| `/download/`، `/dl/<id>/` | صفحهٔ دانلود اپ؛ هر کلیک دانلود شمرده می‌شود |
| `/announcements/`، `/announcements/<slug>/` | اطلاعیه‌ها |
| `/contact/` | فرم تماس |
| `/search/` | جست‌وجو |
| `/newsletter/` | عضویت خبرنامه |
| `/account/`، `/account/login/`، `/account/code/`، `/account/password/`، `/account/logout/` | حساب کاربری سایت |
| `/pay/callback/`، `/pay/callback/<kind>/`، `/pay/result/<token>/` | بازگشت از درگاه پرداخت و صفحهٔ نتیجه |
| `/media/<id>/<name>` | فایل رسانه (از دیتابیس) |
| `/robots.txt`، `/sitemap.xml`، `/rss.xml` | سئو و فید |
| `/11601693.txt` | فایل تأیید اینماد |
| `/<slug>/` | برگه‌ها (دربارهٔ ما، تماس، قوانین، حریم خصوصی، ...) |

صفحهٔ ۴۰۴ سایت از `apps.website.views_public.not_found` است. اگر «حالت تعمیر» در تنظیمات روشن باشد، بازدیدکننده‌ها صفحهٔ «در حال تعمیر» (503) را می‌بینند و کارکنان سایت را عادی می‌بینند.

## حساب و خرید روی سایت

- **حساب مشترک با اپ:** حساب‌ها، پیامک‌ها و قواعد رمز با اپ یکی است. کسی که در سایت ثبت‌نام کند، با همان شماره و رمز وارد اپ می‌شود و برعکس.
- **کاربر قبلی:** با شمارهٔ موبایل یا ایمیل و رمز در `/account/login/` وارد می‌شود.
- **کاربر تازه:**
  1. شماره را با کد پیامکی تأیید می‌کند (`/account/code/`).
  2. در `/account/password/` نام و رمز را انتخاب می‌کند.
  3. کد تأیید به‌تنهایی نشست ورود سایت نمی‌سازد؛ این مرحله باید کامل شود.
- **بازیابی رمز:** با کد پیامکی و انتخاب رمز تازه.
- **مسیر خرید:**
  1. `/plans/`
  2. ثبت‌نام یا ورود
  3. `/checkout/<قیمت>/`
  4. درگاه پرداخت
  5. `/pay/callback/<kind>/`؛ اشتراک روی حساب فعال می‌شود.
  6. صفحهٔ نتیجه
- **پلن «پیشنهادی»:** برای نشان «پیشنهادی» روی یک پلن، نشانی (slug) آن را در «تنظیمات ← صفحهٔ اصلی» بنویسید.

## پنل محتوا (`/panel/`)

نشانی: `https://pharmenta.ir/panel/` (ورود: `/panel/login/`). کد: `backend/apps/website/panel/`.

**ورود:** حساب `is_superuser`، یا حسابی که مدیر در «کاربران و نقش‌ها» به آن نقش داده است. کاربر باید قبلاً در اپ یا سایت حساب ساخته باشد.

| دسته‌ها، برچسب‌ها | `/panel/categories/`، `/panel/tags/` | |
| برگه‌ها | `/panel/pages/` | دربارهٔ ما، قوانین، حریم خصوصی و ... |
| رسانه | `/panel/media/` | تصویر و PDF تا ۵ مگابایت |
| نظرات | `/panel/comments/` | تأیید و رد |

### نقش‌ها

| نقش | دسترسی |
|---|---|
| مدیر (و superuser) | همه‌چیز، تنظیمات، کاربران، گزارش فعالیت |
| سردبیر | همهٔ مطالب و انتشار، برگه‌ها، رسانه، نظرات، اطلاعیه‌ها، دانلودها، منوها، سئو، بلوک‌های صفحهٔ اصلی؛ دیدن سفارش‌ها |
| نویسنده | نوشتن مطلب خودش و ارسال برای بازبینی؛ بارگذاری رسانه |
| پشتیبان | نظرات، پیام‌های تماس، خبرنامه، سفارش‌ها (فقط دیدن) |

### محتوای شروع

`seed_website` در هر شروع کانتینر فقط بخش‌های **خالی** را پر می‌کند و چیزی را که در پنل ویرایش شده بازنویسی نمی‌کند. این بخش‌ها را می‌سازد: منوها، بلوک‌های صفحهٔ اصلی، برگه‌های «دربارهٔ ما»، «تماس»، «قوانین» و «حریم خصوصی»، و پیوند وب‌اپ. برگه‌های قوانین و حریم خصوصی **پیش‌نویس** ساخته می‌شوند؛ متن واقعی را بنویسید و منتشر کنید.

## رسانه

فایل‌های بارگذاری‌شده **در دیتابیس** (مدل `Media`) نگهداری می‌شوند، چون کانتینر بک‌اند دیسک پایدار برای رسانه ندارد. پس بکاپ دیتابیس رسانه‌ها را هم شامل می‌شود. حداکثر حجم هر فایل ۵ مگابایت است. فایل APK را اینجا بارگذاری نکنید؛ در «نسخه‌ها و دانلود» لینک مستقیم یا لینک فروشگاه بگذارید.

## آمار بازدید

- **شمارش:** بازدید صفحه، بازدید مطلب، کلیک دانلود و عضویت خبرنامه روزانه در `website_dailystat` شمرده می‌شوند. ربات‌ها و کارکنان شمرده نمی‌شوند. سایت کوکی یا ردیاب شخص ثالث ندارد.
- **بازدیدکنندهٔ یکتا:** بر اساس IP شمرده می‌شود (`website_visitorday`، یک ردیف برای هر IP در هر روز).
  - **حریم خصوصی:** خود IP ذخیره نمی‌شود؛ فقط یک هش کلیددار با `SECRET_KEY`.
  - **نگهداری:** ردیف‌های قدیمی‌تر از ۴۰۰ روز خودکار پاک می‌شوند.
  - **منبع IP:** IP از `X-Forwarded-For` خوانده می‌شود.
  - **محدودیت:** چند نفر پشت یک IP مشترک یک بازدیدکننده حساب می‌شوند.
  - **`SECRET_KEY`:** عوض کردنش همهٔ بازدیدکننده‌ها را «جدید» می‌کند.
- **آنالیتیکس بیرونی:** کد گوگل آنالیتیکس یا متریکا را در «تنظیمات ← سئو» بگذارید (فقط superuser).

## سئو

برنامهٔ کامل سئو، کلمات کلیدی، تنظیمات Google Search Console و GA4 و robots.txt در [`seo-plan.fa.md`](seo-plan.fa.md) است (همراه `seo-keywords.fa.csv` و `seo-ga4-head.html`). نقشهٔ سایت (`/sitemap.xml`)، فید (`/rss.xml`) و نشانی canonical از `SITE_PUBLIC_URL` ساخته می‌شوند.
