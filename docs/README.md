# مستندات فارمنتا

فارمنتا (Pharmenta) اپ آموزشی داروسازی است: درس‌نامه‌های دارویی، فلش‌کارت، آزمون، برنامهٔ مطالعه، مرجع‌های بالینی (UpToDate، Lexicomp، Medscape)، ماشین‌حساب‌های بالینی و فروش اشتراک. این پوشه مرجع واحد همهٔ اطلاعات فنی پروژه است، از نوشتن کد تا دیپلوی و نگهداری.

> نام قدیمی پروژه «Pharmexa» بود. این نام هنوز در شناسه‌های فنی دیده می‌شود (مثلاً `com.pharmexa.learning`، دیتابیس `pharmexa_dev`، کلیدهای ذخیره‌سازی `pharmexa.*`). این شناسه‌ها عمداً عوض نشده‌اند، چون تغییرشان داده‌ها و نصب‌های موجود را می‌شکند.

## قرارداد نگهداری این مستندات

- هر تغییری که رفتار، دستور، متغیر محیطی یا مسیر API را عوض می‌کند، در همان کامیت در فایل مربوط ثبت شود.
- مقدار هیچ رازی (کلید، رمز، توکن) در این مستندات نوشته نمی‌شود؛ فقط نام متغیر و جای نگهداری‌اش. فهرست رازها در [09-operations.md](09-operations.md#رازها-و-چیزهایی-که-باید-امن-نگه-داشته-شوند) است.
- مسیرهای لپ‌تاپ توسعه (مثل `/home/amir/Documents/...`) همان پیش‌فرض‌هایی هستند که در کد آمده‌اند. روی سیستم دیگر با گزینهٔ `--source` یا متغیر محیطی عوض می‌شوند.
- شکل دقیق هر پاسخ API در Swagger زنده هم هست: `https://api.pharmenta.ir/api/v1/docs/`.
