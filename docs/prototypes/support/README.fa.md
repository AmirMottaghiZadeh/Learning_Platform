# دو طرح پشتیبانی فارمنتا

پیش‌نمایش در [index.html](index.html) با دو حالت و تم روشن/تیره است. همهٔ پیام‌ها و هویت‌ها دادهٔ نمایشی هستند. ارسال نمونه فقط در مرورگر است.

- مدل ۱: گفت‌وگوی مستقیم، صندوق پیام کنار مکالمهٔ مدیر، چت پیوسته برای کاربر.
- مدل ۲: پروندهٔ موضوعی با وضعیت، جدول درخواست‌ها برای مدیر، مکالمهٔ وابسته به هر پرونده برای کاربر.

رنگ‌ها از `frontend/src/theme/tokens.ts` و مدیریت موجود گرفته شده‌اند؛ فونت وزیرمتنِ محلی است. سبک‌های انتخاب‌شده: `framed-sheet` با seed `1129672589` و `achromatic-ledger` با seed `218724598`. پوستهٔ موجود محصول و پالت آن بر سبک مقدم‌اند. مدل ۲ دکمهٔ اصلی با رنگ متن دارد؛ مدل ۱ از سبز اصلی اپ استفاده می‌کند.

انتخاب نهایی کاربر: **مدیریت مدل ۲، چت کاربر مدل ۱**. این ترکیب در کد اصلی پیاده‌سازی شده است؛ فایل HTML این پوشه همچنان پیش‌نمونهٔ دو مدل است.

تصویرهای نسخهٔ پیاده‌شده با حساب‌های ساختگی و دیتابیس آزمایشی مستقل در [implemented/](implemented/) هستند: [چت کاربر](implemented/support-user.jpg)، [چت تیره](implemented/support-user-dark.jpg)، [جدول مدیریت](implemented/support-admin-list.jpg) و [گفت‌وگوی مدیر](implemented/support-admin-chat.jpg).
