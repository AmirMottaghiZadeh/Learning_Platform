# تصویرهای نسخهٔ پیاده‌شده

این تصویرها از اجرای واقعی اپ و مدیریت روی دیتابیس آزمایشی مستقل گرفته شده‌اند. همهٔ حساب‌ها و پیام‌ها ساختگی‌اند. ترکیب انتخاب‌شده: مدیریت مدل ۲ و چت کاربر مدل ۱.

- [چت کاربر روشن](support-user.jpg) و [تیره](support-user-dark.jpg)
- [جدول پرونده‌ها](support-admin-list.jpg)، [گفت‌وگوی مدیر](support-admin-chat.jpg) و [حالت تیرهٔ مدیریت](support-admin-dark.jpg)
- [نقشهٔ فعالیت](usage-admin.jpg) و [دستگاه‌ها](devices-admin.jpg)

رابط در عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شد. بررسی خودکار چیدمان پشتیبانی، پس از حفظ عناصر طراحی موجود محصول، خطای اندازه‌گیری ندارد. رنگ زمینه، سایهٔ قاب وب و دکمه‌های پوسته از سیستم طراحی موجود آمده‌اند. اختلاف نام وزن‌های وزیرمتن به معنی استفاده از سه خانوادهٔ فونت نیست. فضای خالی مکالمه و جدول به تعداد پیام‌ها و پرونده‌های واقعی وابسته است؛ دادهٔ ساختگی به گزارش محیط اصلی اضافه نشده است.

دو ایراد در بازبینی رفع شدند: بنر پیام تازه پس از شش ثانیه کنار می‌رود تا کنترل‌های خواننده را نپوشاند؛ نام کاربر در جدول مدیریت پیوند باز کردن گفت‌وگو است تا در موبایل نیز بدون رسیدن به ستون آخر قابل استفاده باشد.

آزمون مرورگر شامل ارسال پیام کاربر، رسیدن پاسخ مدیر، باز کردن گفت‌وگو از پیوند اعلان و حفظ پیام‌های هم‌زمان است. دریافت Push واقعی وب/اندروید در این محیط تأیید نشده؛ وضعیت تنظیم کلیدها و مراحل Firebase در [سند ۱۷](../../../17-sessions-activity-support.fa.md) ثبت شده است.
