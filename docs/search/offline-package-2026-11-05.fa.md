# همسان‌سازی جست‌وجوی آفلاین UpToDate — ۵ نوامبر ۲۰۲۶

## علت و تغییر

index رمزگشایی‌شدهٔ بستهٔ قبلی `uptodate-1-20261023-5ad32e` فاقد `search_schema`، نگاشت مفهوم‌ها و همهٔ عضویت‌های تخصصی بود. بنابراین کلاینت هنگام خواندن آن به مسیر قدیمی جست‌وجوی واژگانی برمی‌گشت. سازنده و خوانندهٔ مفهومی در تغییر قبلی پروژه موجود بودند؛ برای کاربران تازه‌دانلودکننده لازم بود بسته با همان کد جدید دوباره ساخته شود.

بستهٔ تازه، نگاشت‌های `search.db` را همراه محتوا و تخصص‌های `toc.db` دارد. اولویت نتایج، تشخیص مخاطب، پیشنهاد عبارت، فیلتر تخصص و صفحه‌بندی با مسیر آنلاین همسان است. رتبه‌بندی واژگانی همچنان مسیر جایگزین عبارت‌های فاقد مفهوم است.

در `frontend/src/offline/sources.ts` نصب، جایگزینی یا حذف بستهٔ UpToDate حالا کش نتایج، مقاله و HTML گرافیک را بی‌اعتبار می‌کند. پیش‌تر نتیجهٔ یک جست‌وجوی اخیر می‌توانست تا پنج دقیقه پس از نصب دادهٔ جدید از حافظهٔ قبلی نمایش داده شود. تغییر پیشرفت دانلود یا تغییر بستهٔ Lexicomp این کش را دست نمی‌زند.

پاک‌سازی عنوان و رفع HTML معیوب، تغییر قبلی کلاینت و سازنده است؛ عنوان‌های تمام رکوردهای مقالهٔ بستهٔ تازه نیز بررسی شدند. برای استفاده از این رفتار، اپ جدید باید منتشر شود.

## شواهد بررسی

- اندازه، SHA-256 و MD5 هر ۱۱ قطعه با manifest تطبیق داده شد؛ اشاره‌گر `latest.json` با manifest ساخت یکسان است.
- مرز رکوردها و احراز اصالت AES-GCM تمام ۱۱۴٬۲۳۲ رکورد محتوایی بررسی شد؛ به‌علاوه رکورد index بسته، مجموع manifest برابر ۱۱۴٬۲۳۳ است. عنوان‌های همهٔ مقاله‌ها و داده‌های سرآیند نیز بررسی شدند.
- فایل واقعی رمزگذاری‌شده با `PackageReader`، رمزگشایی WebCrypto و `uptodateLocal` واقعی کلاینت در Node 22 خوانده شد. شبکهٔ API عمداً قطع بود و شمار درخواست شبکه صفر ماند.
- ۳۲ حالت با خروجی واقعی سرویس آنلاین متکی به همان snapshot SQLite تطبیق کامل داشتند: `h pylori` و نام کامل/نقطه‌دار آن، درمان بزرگسال و کودک، تشخیص و آزمایش، عبارت ناقص، diabetes، hypertension، asthma، apixaban، COPD، عبارت ناموجود، چهار تخصص و سه offset صفحه‌بندی.
- جست‌وجوی `h pylori` در بستهٔ تازه ۴۲ نتیجه دارد و نتیجهٔ اول `140619`، مقالهٔ درمان بزرگسالان است؛ در اجرای همان خواننده روی بستهٔ قدیمی، نتیجهٔ اول `15734` بود.
- هفت مقاله از بسته با خروجی آنلاین مقایسه شدند و یک تصویر واقعی نیز خوانده شد.
- `test-offline-source-refresh.cjs` نصب/جایگزینی/حذف بسته، بی‌اعتبار شدن کش و خواندن دادهٔ جدید بدون شبکه را بررسی می‌کند. تست‌های موجود مفهوم، تخصص، صفحه‌بندی، سازگاری بستهٔ قدیمی، عنوان و HTML خواننده نیز گذشتند.
- `npm run typecheck` و `npm run build:web` موفق بودند.

گزارش ماشینی بدون کلید: `/home/amir/offline-packages/uptodate/uptodate-1-20261105-11f5a4-verification.json`.

این بررسی، همسانی دو مسیر روی snapshot فعلی و صحت خواندن فایل واقعی را نشان می‌دهد؛ آزمون نصب APK روی دستگاه فیزیکی یا آزمون محتوای پایگاه MySQL منتشرشده نیست. پیش از انتشار عمومی، دانلود بسته از باکت و باز کردن آن با اپ جدید روی دستگاه واقعی بررسی شود.

## وابستگی به انتشار اپ

آپلود بسته، کد APK قدیمی را تغییر نمی‌دهد. کلاینتی که خوانندهٔ مفهومی جدید را دارد باید همراه این انتشار در دسترس کاربران باشد. با اپ جدید و بستهٔ تازه، جست‌وجوی مفهومی از اولین استفادهٔ بدون اینترنت فعال است و دریافت مکمل لازم نیست. کاربران اپ جدید با بستهٔ قدیمی می‌توانند با یک اتصال موفق و دسترسی معتبر، مکمل رمزگذاری‌شده را بگیرند؛ در نبود آن، همان جست‌وجوی قدیمی قابل استفاده می‌ماند.

## دستور قابل تکرار و کشوی راهنمای انتخاب‌شده

از پوشهٔ `backend`، برای ساخت و بررسی آماده‌بودن فایل‌ها:

```bash
.venv/bin/python manage.py prepare_offline_upload uptodate --source /home/amir/Documents/UpToDate --out /home/amir/offline-packages
```

برای بررسی بستهٔ ساخته‌شده، بدون تولید دادهٔ جدید: `prepare_offline_upload uptodate --out /home/amir/offline-packages --existing`. راهنمای مسیر و ترتیب آپلود در `uptodate/UPLOAD.fa.md` تولید می‌شود. این دستور روی build بالا با موفقیت اجرا شد و هیچ آپلودی انجام نداد.

طرح کشوی راهنما در اپ اصلی پیاده شد. پیشنهادها اکنون تا ۱۲ مفهوم متمایز دارند و `kind/count` را در آنلاین و آفلاین یکسان محاسبه می‌کنند. شمارنده تعداد ارجاع‌های معتبر و یکتای مفهوم است و فیلترهای نمایشی از واژه‌های عبارت ساخته می‌شوند. بستهٔ باینری بالا همچنان معتبر است؛ این داده‌ها از همان index محلی خوانده می‌شوند و تغییر جدید به دانلود بسته‌ای دیگر نیاز ندارد. انتشار کلاینت و بک‌اند به‌روز برای رفتار کامل آنلاین لازم است.
