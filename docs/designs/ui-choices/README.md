# انتخاب‌های تأییدشده

- `index.html?kind=home`: کارت سرچ خانه، **مدل ۲**.
- `index.html?kind=auth&mode=signup`: ثبت‌نام، **مدل ۳**.
- `index.html?kind=auth&mode=login`: لاگین، **مدل ۳**.
- `index.html?kind=table`: ستون اول جدول، **مدل ۲**؛ خطوط تمام سلول‌های مستقل حفظ شوند. نمونه پس از بازخورد مالک اصلاح شد تا خط کنار rowspan حذف نشود.

پیش‌نمایش‌ها دادهٔ نمونه دارند. جزئیات اجرای واقعی و انتشار در [سند ۴۳](../../43-smart-search-postpay-quality-ai.fa.md) است.
