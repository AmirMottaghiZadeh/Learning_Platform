# پنج مدل صفحهٔ بیماری‌ها و گایدلاین‌ها — ۲۰۲۶-۱۱-۲۶

فایل را مستقیم در مرورگر باز کنید؛ سرور یا اینترنت لازم نیست. فونت وزیرمتن کنار فایل کپی شده است.

```
xdg-open docs/designs/browse-2026-11/index.html
```

## چه چیزی را نشان می‌دهد

مشکل صفحهٔ فعلی: علاقه‌مندی‌ها ← تازه‌ها ← جست‌وجو ← فهرست A–Z همه پشت هم چیده شده‌اند، پس ابزار اصلی (جست‌وجو و خود فهرست) زیر خط دید می‌رود. این پنج مدل پنج منطق چیدمان متفاوت برای رفع همین مشکل‌اند:

| مدل | ایده | حرف دسته |
|---|---|---|
| ۱ جست‌وجو اول | جست‌وجو زیر سربرگ و چسبیده به بالای صفحه؛ ذخیره‌شده و تازه‌ها به تب تبدیل می‌شوند | نشان سبز پر با شمار مقاله، چسبان |
| ۲ نوار حروف | کل صفحه به فهرست A–Z تعلق دارد؛ جست‌وجو اختیاری و کوچک | نوار حروف کنار لبه + حرف بزرگ سبز با خط |
| ۳ دسته‌بندی اول | دو دکمهٔ کوچک ذخیره/تازه، چیپ موضوع‌ها، سپس فهرست | نوار کم‌رنگ تمام‌عرض با نوار رنگی کنار |
| ۴ تب‌دار + جست‌وجوی شناور | سه تب حالت‌ها؛ جست‌وجو همیشه پایین صفحه | دایرهٔ توخالی روی خط زمان |
| ۵ کارت موضوعی | کارت‌های موضوع با شمار مقاله، پیش‌نمایش کوتاه فهرست | مربع خط‌چین سبز |

بالای صفحه سه سوییچ دارد: فارسی/انگلیسی، روشن/تیره، و بیماری‌ها/گایدلاین‌ها. مدل «همه در یک نگاه» هر پنج مدل را کنار هم نشان می‌دهد. نشانی هر مدل قابل ذخیره است:

```
index.html?model=3&theme=dark&lang=en&ctx=guideline
```

## پیاده‌سازی بعد از انتخاب

مدل منتخب برای دو صفحه ساخته می‌شود: فهرست مقاله‌های بیماری‌ها (`MedscapeSpecialtyScreen`) و گایدلاین‌ها (`MedscapeGuidelinesScreen`). داده و API تغییری نمی‌کند؛ فقط چیدمان و کامپوننت‌های مشترک (`AlphabeticalArticleList`، `ReferenceFavorites`).

## نتیجهٔ پیاده‌سازی — ۲۰۲۶-۱۱-۲۶

مالک پروژه **مدل ۵ (کارت موضوعی)** را انتخاب کرد و پیاده شد:

- **بیماری‌ها و شرایط** (`MedscapeBrowseScreen`): جست‌وجو ← تب دسته (Medicine / Pediatrics / Surgery) ← گرید دوستونهٔ تخصص‌ها با آیکون، نام و شمار مقاله. با لمس هر کارت، صفحهٔ آن تخصص باز می‌شود. (مالک بعداً خواست گرید و تب‌ها هر دو بمانند؛ فقط ترتیب عوض شد تا جست‌وجو بالای همه باشد.)
- **صفحهٔ تخصص** (`MedscapeSpecialtyScreen`): جست‌وجو ← شمار مقاله ← فهرست A–Z با نشان حرف.
- **گایدلاین‌ها** (`MedscapeGuidelinesScreen`): جست‌وجو ← نوار کارت موضوع (سه نوع محتوا) ← فهرست A–Z. «تازه‌ها» به یک دکمهٔ کوچک کنار عنوان فهرست تبدیل شد.
- علاقه‌مندی‌ها در هر سه صفحه به یک چیپ ★ در سربرگ تبدیل شدند و فقط با لمس باز می‌شوند.
- کامپوننت‌های مشترک تازه: `components/medscape/{TopicCard,TopicRail,LetterBadge,BrowseSearch,FavoritesChip}`.
