# آزمون دسته‌بندی‌شده و حذف فلش‌کارت

وضعیت کد: ۲۰۲۶-۱۱-۰۷.

## رفتار فعلی

نوار پایین فقط «خانه، دارونامه، پروفایل» است. آزمون از «خانه ← آموزش ← آزمون»، برنامهٔ مطالعه و خودآزمایی دارو در دسترس است. صفحهٔ انتخاب آزمون همان شبکهٔ دسته‌ها و فهرست موضوع‌های فلش‌کارت قبلی را استفاده می‌کند: دسته ← زیردسته ← فصل اختیاری و تعداد سؤال ← سؤال‌ها. دسته‌بندی از API دارونامه می‌آید و با `category` (کد موضوع) و `atc_code` به پیش‌نمایش/شروع آزمون می‌رسد. زیرگروه با دادهٔ ناکافی پیام مشخص و شروع غیرفعال دارد. انتخاب‌های فصل و تعداد سؤال تغییر پیش‌نمایش را به دنبال دارند.

فایل‌ها: `frontend/src/components/quiz/QuizSetup.tsx`، `screens/QuizScreen.tsx`، `utils/lessonCategories.ts`، `navigation/types.ts` و `components/BottomNav.tsx`. مسیر آزمون با `navigate` باز می‌شود تا برگشت به صفحهٔ قبلی حفظ شود؛ دیگر TabKey نیست.

## حذف داده‌های کاربران

با اجرای `python manage.py migrate` این موارد برای همهٔ کاربران حذف می‌شوند:

- جدول‌های `LeitnerCard` و `TopicProgress` و همهٔ تاریخچه/زمان‌بندی فلش‌کارت آن‌ها؛
- شمارندهٔ `LearnerProgress.total_reviews` و تمام کارهای برنامه با `activity_type=flashcards`، حتی انجام‌شده/ردشده؛
- رویدادهای فعالیت بخش فلش‌کارت و سهمیهٔ مصرف همان قابلیت؛
- ویژگی فروش فلش‌کارت، ارتباطش با پلن‌ها و کلید همان قابلیت در snapshot دسترسی کاربران.

این حذف با برگشت مهاجرت، اطلاعات قبلی را بازیابی نمی‌کند. سابقهٔ آزمون، پاسخ‌ها، اشتباهات، خواندن دارونامه، پرداخت‌ها، دسترسی به سایر قابلیت‌ها و دقیقه/XP تجمیعی مشترک حساب حفظ می‌شوند. دقیقه/XP تاریخی به‌تفکیک قابلیت ثبت نشده‌اند و از روی شمار مرور قابل تفکیک دقیق نیستند.

محتوای بدون دادهٔ کاربر `FlashcardFact` به مالکیت `quiz.StudyFact` منتقل شده است. مهاجرت از `SeparateDatabaseAndState` استفاده می‌کند تا همان جدول و دادهٔ مشترک باقی بمانند؛ جدول فیزیکی و نام‌های فایل انتقال عمداً تغییر نکرده‌اند. اپ `apps.flashcards` فقط برای اجرای مهاجرت‌های تاریخی در `INSTALLED_APPS` می‌ماند؛ مدل، سرویس، دستور، ادمین و API فعالی ندارد. ثبت آن را از تنظیمات حذف نکنید.

لینک‌های اعلان قدیمی به دارونامه منتقل می‌شوند. گزینه‌های مربوط به فلش‌کارت از مدیریت اعلان و نمایش سایت حذف شده‌اند. متن‌ها و نمایش‌های پیش‌فرض سایت نیز قابلیت حذف‌شده را تبلیغ نمی‌کنند. مقاله‌های عمومی دربارهٔ روش‌های یادگیری و تاریخچهٔ انتشار، سابقه‌اند.

## کش دستگاه و انتشار

نسخهٔ کش TanStack Query تغییر کرده تا اطلاعات مرور قبلی بازیابی نشود. صف فعالیتِ هر حساب رویدادهای باقی‌ماندهٔ فلش‌کارت را پیش از ارسال کنار می‌گذارد. بسته‌های آفلاین مرجع دست‌نخورده‌اند.

بک‌اند و اپ جدید را در یک انتشار هماهنگ تحویل دهید. سرور باید مهاجرت‌های هفت اپ `quiz`، `flashcards`، `progress`، `billing`، `activity`، `announcements` و `website` را اعمال کند. نسخهٔ قبلی اپ نمی‌تواند از API حذف‌شدهٔ فلش‌کارت استفاده کند. روی سرور تا زمان دیپلوی و اجرای migration، دادهٔ موجود تغییر نمی‌کند. اعلانات پشتیبانی طبق تنظیم قبلی همچنان خاموش‌اند.

## بررسی

تست ارتقای واقعی در `backend/apps/quiz/test_retire_flashcards.py` حذف جدول‌های سابقه و حفظ نکتهٔ مشترک، آزمون، دسترسی سایر بخش‌ها و فعالیت آزمون را کنترل می‌کند. تست‌های آزمون/برنامه/فروش/سایت، TypeScript، بیلد وب و مسیر دسته تا سؤال در مرورگر نیز باید موفق باشند.

نتیجهٔ بررسی محلی این تغییر: هر ۸۲۷ تست بک‌اند و ۱۳ تست اسکریپت فرانت‌اند موفق؛ `npm run typecheck` و `npm run build:web` موفق. در مرورگر، انتخاب دسته/زیردسته، شروع و پاسخ آزمون، برگشت مرحله‌ای و تغییر فارسی/انگلیسی بررسی شد؛ در عرض‌های ۳۷۵، ۷۶۸ و ۱۴۴۰ پیکسل بیرون‌زدگی افقی وجود نداشت. سایهٔ قاب اصلی اپ، طبق طراحی موجود محصول، حفظ شده است. تصاویر واقعی خانهٔ روشن/تیرهٔ سایت نیز با ناوبری سه‌گزینه‌ای جایگزین شدند.

مهاجرت‌ها روی پایگاه دادهٔ محلی اعمال شده‌اند: جدول‌های سابقه، کارهای برنامه و سهمیهٔ فلش‌کارت باقی نمانده‌اند و ۱۸٬۵۵۶ نکتهٔ مشترک حفظ شده است. این نتیجه به معنی اجرای مهاجرت روی سرور انتشار نیست.
